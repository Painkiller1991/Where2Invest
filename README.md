# Where2Invest

اپ لوکال فارسی برای تصمیم‌گیری «کجا سرمایه‌گذاری کنم؟» با دادهٔ واقعی انس طلا و دلار آزاد ایران، پیش‌بینی چندماهه، و مقایسهٔ روش‌های سرمایه‌گذاری.

## چه کار می‌کند؟

1. **آپدیت داده** — انس طلا (Yahoo `GC=F`) و دلار آزاد (Bonbast / TGJU)، کش SQLite افزایشی از ۲۰۱۸
2. **چارت معاملاتی** — کندل + ابزار رسم (مثل Investing)، تمام‌صفحه و Undo
3. **پیش‌بینی** — احساس بازار (−۱۰…۱۰) + افق ماه؛ LightGBM و Prophet؛ مقایسهٔ واقعی vs پیش‌بینی و تایید
4. **مدل‌های سرمایه‌گذاری** (روی افق پیش‌بینی تاییدشده):
   - **فین‌تک** — وام → خرید یک‌جا → اقساط ماهانه (مقدار دارایی ثابت)
   - **خرید مستقیم** — سرمایه اولیه + DCA ماهانه با قیمت هر ماه
   - **بانک → وام** — دو زیرمسیر: ماهانه به بانک (امتیاز بیشتر) یا ماهانه خرید دارایی تا موعد وام
5. **دارایی‌ها** — طلای گرم ۱۸ (ذات انس×دلار، بدون اجرت/حباب)، دلار آزاد، صندوق درآمد ثابت روزشمار
6. **توصیه نهایی** — با بودجه ماهانهٔ مشترک و تاییدشده، می‌گوید کدام راه + چه بخری احتمالاً پرسودتر است

## استک

| لایه | فناوری |
|------|--------|
| Backend | FastAPI, pandas, yfinance, LightGBM, Prophet, SQLite |
| Frontend | React (Vite), TypeScript, KLineChart |
| Config | `config.yaml` |

## پیش‌نیاز

- Python 3.11+ (پیشنهادی)
- Node.js 18+ و npm
- Windows PowerShell (اسکریپت `start.ps1`)

## اجرا (سریع)

از ریشهٔ پروژه:

```powershell
.\start.ps1
```

اسکریپت venv می‌سازد، وابستگی‌ها را نصب می‌کند، API و UI را بالا می‌آورد.

- **UI:** http://127.0.0.1:5173  
- **API docs:** http://127.0.0.1:8000/docs  
- **مقایسه مدل‌های پیش‌بینی (HTML):** [`docs/prediction-models.html`](docs/prediction-models.html)

## اجرا (دستی)

```powershell
# ۱) محیط پایتون
python -m venv .venv
.\.venv\Scripts\pip install -r backend\requirements.txt

# ۲) API
$env:PYTHONPATH = "$PWD\backend"
.\.venv\Scripts\python -m uvicorn app.main:app --app-dir backend --reload --host 127.0.0.1 --port 8000
```

ترمینال جدا برای فرانت:

```powershell
cd frontend
npm install
npx vite --host 127.0.0.1 --port 5173
```

## جریان استفاده

1. مرحلهٔ داده را تا «آماده» پیش ببر (Retry / دانلود کامل در صورت خطا)
2. احساس طلا و دلار + تعداد ماه را بزن → پیش‌بینی
3. نمودار واقعی در برابر پیش‌بینی را ببین و **تایید** کن
4. سرمایه اولیه، پارامتر وام‌ها، تیک دارایی‌ها را پر کن → **پیشنهاد بودجه ماهانه** → **تایید بودجه** → محاسبه
5. باکس توصیه و جدول مقایسه را ببین

## ساختار پوشه

```
Where2Invest/
  backend/app/          # FastAPI، سرویس‌های داده/پیش‌بینی/سرمایه‌گذاری
  frontend/src/         # React UI
  data/                 # SQLite کش (در git نیست)
  docs/                 # مستندات مدل‌های پیش‌بینی
  config.yaml           # تنظیمات تاریخ شروع، منابع، ثابت‌های طلا
  start.ps1             # راه‌اندازی یک‌کلیکی
```

## APIهای مهم سرمایه‌گذاری

- `POST /api/invest/suggest-monthly` — پیشنهاد بودجه = مکس اقساط مدل‌های وام فعال
- `POST /api/invest/compare` — مقایسه مسیرها + `recommendation` فارسی

## نکات

- اپ کاملاً **لوکال** است؛ نیاز به اینترنت فقط برای دانلود/آپدیت داده و وابستگی‌ها
- فایل `data/market.db` کش محلی است و commit نمی‌شود
- پیش‌بینی و مقایسه سرمایه‌گذاری **توصیه قطعی مالی نیستند**؛ ابزار کمکی روی فرض‌های خودت هستند
